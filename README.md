# SocialPilot Frontend

A modern and responsive frontend for **SocialPilot**, a social media management platform that enables users to manage multiple social media accounts, schedule posts, monitor analytics, and manage their profile from a single interface.

---

## Overview

SocialPilot is designed to simplify social media management by providing an intuitive dashboard with a clean and modern user experience. This project focuses on building a scalable frontend architecture using React and reusable UI components.

---

## Features

- Dashboard with social media overview
- Social account management
- Analytics dashboard
- User profile management
- Account settings
- Authentication pages (Login & Register)
- Responsive sidebar navigation
- Modern and clean user interface
- Reusable component-based architecture

---

## Tech Stack

 Technology : Purpose

## Installation

Clone the repository

```bash
git clone https://github.com/your-username/socialpilot-frontend.git
```

Navigate to the project directory

```bash
cd socialpilot-frontend
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```
